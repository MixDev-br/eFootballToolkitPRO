# eFootball Toolkit PRO 2.1

[Português](README.md) • [English](README.en-US.md) • [Español](README.es-ES.md)

eFootball Toolkit PRO brings match monitoring, an in-game overlay, game modes, and network tools together in an interface made for eFootball players.

[Official website](https://mixdev-br.github.io/eFootballToolkitPRO/?lang=en) • [Android + OpenWrt guide (Portuguese)](OPENWRT_MOBILE_GUIDE.md) • [Support](mailto:efootballtoolkitpro.suporte@gmail.com)

## Main features

- live ping, region, distance, endpoint, packet loss, and FPS;
- compact, movable, and customizable overlay;
- P2P, PSP/dedicated server, and LAN detection over IPv4 and IPv6;
- X1, COOP, and custom modes;
- server center with measurements and regional selection;
- match history, opponent records, and rematch alerts;
- Xbox and PlayStation controller diagnostics;
- support for eFootball on Steam and Xbox PC;
- PC, PlayStation, and Xbox monitoring through an OpenWrt router;
- interface available in Portuguese, English, and Spanish.

## Available editions

### Windows

- **Trial:** 5 days, no key or payment card required, with essential features.
- **PRO:** full monitor, overlay, server center, history, and tools.

On Windows, capture can use the [official Npcap](https://npcap.com/#download) or a compatible OpenWrt router.

### Android

Toolkit Mobile monitors a PC or console through an OpenWrt router. Your phone, monitored device, and router must be on the same local network. Read the [requirements and installation guide](OPENWRT_MOBILE_GUIDE.md) before installing.

## Getting started on Windows

1. Download Npcap from its official website and keep the installer’s recommended options.
2. Download and extract the complete Toolkit ZIP archive.
3. Open the app and select your network adapter.
4. Start the monitor and open eFootball.
5. Customize the overlay and modes to your preference.

## Security and privacy

- Toolkit does not modify eFootball files;
- app rules are temporary and removed when the session ends;
- the OpenWrt administrator password is used only during guided installation and is not stored;
- no router port needs to be exposed to the internet;
- the license is linked to the device provided during activation or purchase.
