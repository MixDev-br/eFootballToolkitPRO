## Português

- Ao configurar o OpenWrt, o aplicativo sugere automaticamente o endereço do roteador a partir da rede Wi-Fi atual.
- A Central de Servidores permite testar e organizar destinos, com filtro por país.
- Melhorias de estabilidade e de apresentação das informações.

## English

- When setting up OpenWrt, the app suggests the router address from the current Wi-Fi network.
- The Server Center lets you test and organize destinations, with a country filter.
- Stability and display improvements.
