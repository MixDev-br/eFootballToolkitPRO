## Português

- Ao configurar o OpenWrt, o aplicativo sugere o endereço do roteador usando a rede Wi-Fi atual.
- A Central de Servidores permite testar e organizar destinos, com filtro por país.
- Esta versão também chega a quem instalou a atualização anterior antecipadamente.

## English

- When setting up OpenWrt, the app suggests the router address from the current Wi-Fi network.
- The Server Center lets you test and organize destinations, with a country filter.
- This version also reaches customers who installed the previous update early.
